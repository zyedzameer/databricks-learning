# Spark Databricks Learning

This repository documents my journey from enterprise Spark/Scala batch engineering to modern Databricks lakehouse engineering.

## Goal

To become an early adopter of Databricks in my organization by mapping my existing Spark, Scala, ETL, production support and leadership experience to cloud-native Databricks workflows.

## Learning Phases

1. Spark foundation revision
2. Python for data engineering
3. PySpark
4. Databricks fundamentals
5. Delta Lake deep dive
6. Performance tuning
7. Unity Catalog
8. Streaming
9. Cloud architecture
10. Real-world production patterns

## Documentation Format

Each topic will follow this structure:

- Concept
- Why it exists
- Internal working
- Production problem solved
- Databricks mapping
- Pitfalls
- Example code
- Optimization notes
