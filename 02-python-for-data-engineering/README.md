# Python for Data Engineering

## Purpose

Learn practical Python required for PySpark, Databricks notebooks, automation and data engineering workflows.

## Topics

- Variables
- Functions
- Loops
- Lists
- Dictionaries
- Sets
- Tuples
- List comprehension
- Lambda
- Map/filter
- JSON handling
- File handling
- Exception handling
- Basic classes

## Goal

Not to become a full Python software engineer first, but to become comfortable enough to use Python effectively in Databricks and PySpark.
